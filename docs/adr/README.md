# Architecture Decision Records

A short note per significant decision: what was decided, why, and what it cost.

The point is not ceremony. It is that in four months somebody — quite possibly you —
will look at a piece of this and think "why on earth is it done that way," and the
honest answer will have been forgotten. An ADR is two minutes now against an hour then.

Write one when a decision is **hard to reverse** or **will look wrong without context**.
Not for everyday choices.

Never edit a decided ADR. If it changes, write a new one and mark the old **Superseded**.
The record of having been wrong is part of the value.
